CarTV - Screen Share

Foreground services review

Recorded on an isolated Android emulator using a synthetic local sample video. This demonstrates the phone app, not Android Auto vehicle compatibility. Advertising and purchases are disabled in the QA recording.

  1. 0:06 - Start broadcast in the app; Android screen-sharing consent.
  2. 0:12 - Active broadcast with an ongoing notification and a stop action.
  3. 0:18 - Broadcast stopped by the user; the temporary receiver link is revoked.
  4. 0:21 - User selects local media; video playback and media-session notification.
  5. 0:32 - User opens picture-in-picture; playback continues outside the app.

Screen capture begins only after Android consent. Media playback starts only when the user selects media. These services keep those visible, user-initiated tasks running and provide stop/playback controls. Interrupting them would unexpectedly stop the ongoing broadcast or playback.
